About the Project
--------------------
Ekklesia Classroom is an online learning platform designed to connect students and teachers in a virtual environment. It enables smooth communication, class management, and learning resource sharing.

Key Features
-------------------
Virtual Classroom:- Conduct and attend online classes in a structured environment.
Class Scheduling:- Teachers can schedule classes and students can view upcoming sessions.
Attendance Management:- Track student attendance for each class.
Syllabus Management:- Organize and display course syllabus for better learning flow.
Notes Sharing:- Teachers can upload and share study materials with students.
Student–Teacher Interaction:- Enables better communication between students and teachers.

Technical Implementation
-------------------------
Built using React.js
Used useState for managing component-level state
Used useEffect for handling lifecycle events and data updates
Implemented useContext for global state management across components
Used useParams for dynamic routing
Used useNavigate for navigation between pages
Created a mock database stored in the public folder to simulate backend data
Designed using a component-based architecture for scalability and reusability.

Objective
---------------
The goal of this project is to simulate a real-world classroom system and to improve skills in my frontend development, state management, and application structuring using React.
